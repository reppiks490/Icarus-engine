## Scope and method

OCR was run on one sampled frame per second across all three recordings (132 samples total). Consecutive samples repeat the same on-screen message while it remains visible; the repetitions are retained so text changes remain time-indexed. OCR errors are possible; `[unclear]` means the capture/OCR did not support a reliable reading. UI chrome and tool activity are included where detected. Temporary signed image-storage URLs shown in a few screenshots are redacted.

The source videos remain local in `/workspace/agent-recordings/`; they are not committed to any repository.
